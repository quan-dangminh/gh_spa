Invoice / Master Data Management

A minimal web UI to add/remove Employees, Customers, Items and Invoices using Supabase. Connection is read from environment variables on the server (SUPABASE_PROJECT_URL and SUPABASE_PUBLISHABLE_KEY) or edited in each page's connection panel.

Pages

  • Employees (add/remove)
  • Customers (add/remove)
  • Items (add/remove)
  • Invoices (add/remove)

Notes

  • This UI expects the following Supabase tables (with at least an auto-generated id and created_at timestamp): employee, customers, items, invoices.
  • Set SUPABASE_PROJECT_URL and SUPABASE_PUBLISHABLE_KEY in a .env file used by the server to auto-connect. The keys are injected into pages at runtime.
